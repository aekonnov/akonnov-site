Stage 04 · print layouts

Design becomes
a production package

Every component has a material, size, print method and finishing process. Layouts are assembled against the real requirements of the chosen manufacturer and verified before the print run goes live.

Discuss layoutsGo to production

Stage objective

Align artwork, construction and technology

A specification is fixed: component count, formats, materials and print run size.

Layouts are adapted for bleed, cut lines, creasing and colour profile.

Fonts, images, transparency and resolution pass a technical preflight check.

Before the run, colour proof, sample or test kit are evaluated.

Production flow

Five checkpoints before the print run

01

Specification

Component list, dimensions, materials, print run and kit assembly.

02

Requirements

Contractor templates, tolerances, profiles and finishing methods.

03

File assembly

Dielines, bleed, marks, embedded fonts and images at correct resolution.

04

Preflight

Technical check of every file and completeness audit.

05

Sample

Verification of colour, cut, assembly and readability of the physical kit.

Stage output

Approved production package

The deliverable is a specification, verified print files and documented manufacturing parameters, which the contractor can use to price and produce the run.

Print run: board-game production starts at 100 copies; cost depends on component mix, materials, finishing and kit assembly.
