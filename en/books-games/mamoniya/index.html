A board game about Nyandoma district

Mamoniya

An educational board game that turns the history, landmarks and events of the territory into a lively game route.

Case breakdownOriginal source ↗

Project brief

Turn district history and landmarks into an engaging board game

Source material — landmarks, historical facts, interesting locations and notable events of Nyandoma district.

Game format — an accessible roll-and-move game where educational content becomes part of the route and player actions.

Author and developer — Anton Konnov; authorship is also printed on the game box.

Outcome — a unique commissioned board game with its own theme, mechanics, design and a complete set of components.

Physical outcome

Design, packaging and components

What this case shows

A commissioned game is not a repainted template

Mamoniya demonstrates a full development cycle for a specific theme: gathering and adapting source material, designing mechanics, building a visual system, producing print layouts and releasing a physical product. A cost-effective print run for a board game starts at 100 copies.
